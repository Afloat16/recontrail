## 合成照片端到端重建

场景由 `demo.py` 在本地生成，使用三个不同深度的有纹理平面和 8 个相机位置，图像为 720 × 540。所有纹理和场景均为项目自建，没有复用外部照片或模型。重建读取照片和标定内参，**不读取 `ground_truth.json` 的位姿或表面真值**；真值只供测试断言独立核对。

记录配置：最多 2,000 个 SIFT 特征/图，最终优化点预算 1,200，最多 15 次函数评估，CPU lite 后端。

| 指标 | 独立保存的一次实际运行 |
|---|---:|
| 注册照片 | 8 / 8 |
| 优化前候选点 | 3,203 |
| 最终稀疏点 | 1,199 |
| 中位重投影误差 | 0.173775 像素 |
| 95 分位重投影误差 | 0.498318 像素 |
| 优化损失 | 259.772237 → 102.475768 |
| 优化状态 | 接受，收敛，13 次函数评估 |
| 输出尺度 | 任意尺度 |

最终 1,199 点来自长轨迹预算子集再次过滤，不是“所有候选点都成功重建”。上述像素误差是缩放/去畸变图像上的观测重投影误差。测试还用已知基线和第一相机位置消除尺度/原点自由度，检查所有相机中心的最大误差小于 0.03 个场景单位，点到最近真值深度平面的中位误差小于 0.03 个场景单位。该简化场景不能证明复杂真实几何精度。

## 标定双目

取同一合成场景的前两帧，输入正确的双目标定，基线约 0.235666 米，深度上限 15 米，点采样步长为 2。实际结果为 **53,735 个彩色点、104,790 个三角面**，有效视差像素占比约 55.25%。

测试验证：深度为正且有限、左右一致性过滤有效、点到最近真值深度平面的中位误差小于 0.02 米、OBJ 面索引合法、反向双目输入被拒绝。输出为可见表面的开放网格，不闭合、不补洞、不带 UV 贴图，也不保证测量精度。有效像素占比不是几何准确率。

已通过 setuptools 的 PEP 517 本地后端成功构建 `recontrail-0.1.0-py3-none-any.whl`。当前环境的 `pip wheel` 前端一次执行超时，因此改用同一 setuptools 后端直接构建；不将该次前端超时记为通过。
