# 后续维护顺序

本页记录开发方向，不是已实现功能，也不承诺发布日期。

## 优先验证与稳定性

首先在明确允许下载和评测的真实多视角数据集上建立基准，包含失败案例和采集条件；分离许可约束，不把外部照片直接纳入仓库。随后实际运行 Windows / macOS CI、PyCOLMAP 导入和重建验证、完整浏览器上传到报告验收，并记录依赖版本。对低纹理、近似平面、重复图案、纯旋转、混合内参和大规模输入建立回归集。

## 采集与互操作

在保持误差口径透明的前提下完善补拍建议、连通分量选择和多模型结果展示；增加逐相机标定文件、稳健的焦距自标定或明确的后端切换。按照用户需求评估 HEIC、更多网格格式和真实尺度约束，所有新增格式都应有读取回归测试。

## 更完整的表面重建

评估可选稠密多视图后端、深度融合、网格重建、纹理图集和大点云 WebGL 查看。每项必须先说明内存/硬件、依赖许可和输出准确性边界。不会把现有稀疏点云改名为稠密模型，也不会把补洞结果当作真实观测表面。

## 分发

优先实现可复现锁定环境和经验证的安装包，然后再考虑桌面打包。保持默认本地处理、无账户和无遥测；如需远程任务，必须另行设计鉴权、任务隔离和资源配额，不能直接开放当前本机服务器。
